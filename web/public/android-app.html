The darktable app isn't on this phone

You see this page because the darktable app did not open: it is probably not installed on this device. “Edit on this phone” opens the photos in that app, which edits them on the phone and sends the edits back to LightPhotoLibrary.

Where to get it: the app (an unofficial Android port of darktable) is published as release files. Open the newest release (its title starts with “dt-android”) and install the file dt-android-arm64-v8a.apk from it.

darktable for Android: releases

After installing it, add this library's address and password in the app once, then tap “Edit on this phone” again.
